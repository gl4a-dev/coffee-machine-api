# coffee-machine-api
Projeto da Disciplina ACH2006 - Engenharia de Sistemas de Informação, ministrada na EACH-USP.

Aplicação de conhecimentos e técnicas de Engenharia de Software não construção de uma API REST que simule uma máquina de café, tendo seus requisitos bem definidos.

## Setup

### Ambiente Virtual
Crie e ative um ambiente virtual na raiz do projeto:

* Ubuntu
```bash
python3 -m venv .venv
source .venv/bin/activate
```

* PowerShell
```bash
python -m venv .venv
.venv/Scripts/activate
```

### Dependências
Instale as dependências e bibliotecas utilizadas no projeto.

```bash
pip install -r requirements.txt
```
